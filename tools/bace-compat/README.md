# bace-compat

Actual golden fixtures generated by compiling **unmodified official ACE C# source** at `47edade3bd3f6044b676d4eb877c4965c7eda62b`. The generator checks source bytes against immutable official GitHub paths and records SHA-256 hashes. No fork sources, Rust-generated expected outputs, real player captures, credentials or DAT assets are used.

Implemented evidence: header/fragment bytes, header hashes, Hash32 lengths 0–32, 600 successive ISAAC outputs for each of four seeds (including refill boundaries), CP1252 strings/alignment, packed integer boundaries, connect-request payload, clear/encrypted full server packets and retransmits, optional transport-header combinations, and nine inbound login payloads including UTF-8/UTF-16 lengths and long secret prefixes.

Regenerate (requires .NET 10 and Python 3; output is the tracked synthetic fixture):

```sh
python3 tools/bace-compat/oracle/generate.py --source .reference/ACE-47edade3bd3f6044b676d4eb877c4965c7eda62b --dotnet /path/to/dotnet
cargo test -p bace-compat
```

Omit `--source` to fetch source from the pinned official repository. Builds occur in a temporary directory. The small C# harness only constructs inputs and invokes official implementations. Reference source retains upstream licensing; Rust algorithm ports are AGPL-3.0-only.

Full loss/reorder/session transcript replay, all game-opcode payloads, full gameplay/world movement differential replay and stock-client end-to-end compatibility remain unsupported. Passing these vectors establishes only the explicitly enumerated codec subset.

The login oracle invokes the unmodified official `PacketInboundLoginRequest` and `BinaryReaderExtensions` with a harness-only `ClientPacket` data-reader adapter. This isolates payload decoding; it does not claim to exercise official socket routing or `ClientPacket.Unpack`. All credential strings in these fixtures are generated synthetic test inputs.

Message fixtures exercise compiled pinned serializers/handlers, including null boot
reasons, empty fellowship completion, property-string ordering and movement flag
combinations. Transport fixtures compile verbatim extracted NetworkSession methods
with harness adapters and record method hashes. The 504-byte upstream tail case is
a documented 484-byte-bounded deviation. Replication counters compare full C#
advancement through wrap boundaries. Every harness records what it isolates;
these are not full live ACE/server transcript or stock-client tests.
